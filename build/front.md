# About this book {.unnumbered}

This is a free, open book about one idea and what happened when I tried to test it.

The idea: consciousness might not be something only brains do. It might be one case of a much more general process, the way possibilities turn into definite facts. I call that process *actualization*.

This isn't a finished theory, and I'm not presenting it as one. Each chapter starts with an intuition as it first occurred to me, then checks it against established physics, then says honestly what survived.

**How to read it.** Every major claim is tagged:

- **[E] Empirical:** can be tested by observation or experiment, or already has been.
- **[F] Formalizable:** could be expressed mathematically, but no test exists yet.
- **[P] Philosophical:** no observation could settle it as currently stated.

**Feedback.** Each chapter has a discussion thread at <https://github.com/ledodge/actualization/discussions>. For specific errors, please open an issue at <https://github.com/ledodge/actualization/issues>.
