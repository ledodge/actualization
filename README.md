# Actualization

### A physics student's evolving theory of how things become real

**by Lindsey E. Dodge**

📄 [Download the whole book as a PDF](actualization.pdf)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24398682.svg)](https://doi.org/10.5281/zenodo.24398682)

---

This is a free, open book about one idea and what happened when I tried to test it.

The idea: consciousness might not be something only brains do. It might be one case of a much more general process, the way possibilities turn into definite facts. I call that process *actualization*.

This isn't a finished theory, and I'm not presenting it as one. Each chapter starts with an intuition as it first occurred to me, then checks it against established physics, then says honestly what survived. Some ideas held up. Some had to be rebuilt. Some turned out to be wrong, and I've left them in so you can see how that happened.

I'm an undergraduate physics student. I'm writing in public because I want the ideas tested by people who don't already agree with me.

## How to read this book

Every major claim is tagged:

- **[E] Empirical:** can be tested by observation or experiment, or already has been.
- **[F] Formalizable:** could be expressed mathematically, but no test exists yet.
- **[P] Philosophical:** no observation could settle it as currently stated.

If you find a claim with the wrong tag, or no tag, please tell me.

## How to give feedback

The criticism I'm most hoping for:

- **Physics errors.** Something stated incorrectly, or established work I've missed.
- **Logic errors.** Places where the argument contradicts itself or skips a step.
- **Mislabeled claims.** Something tagged [E] that can't actually be tested, or the reverse.
- **Existing work.** If someone has already had one of these ideas, point me to it.

Each chapter has its own thread in [Discussions](https://github.com/ledodge/actualization/discussions). For a specific error, please [open an issue](https://github.com/ledodge/actualization/issues) and include the chapter and the passage.

Disagreement is welcome. "This is wrong because..." is the most useful thing you can write.
